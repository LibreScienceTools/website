Introduction

PDF Citation Extractor is a tool designed to help scientists and researchers manage their references more efficiently. Instead of manually extracting citation information from PDFs one by one, this tool automatically processes PDF files, extracts metadata (DOI, author, title, journal, etc.), and generates a bibliography file (.bib) that can be imported into reference management software like Citavi, JabRef, or Zotero.

Key Features:
  • Automatic DOI extraction from PDF files
  • Metadata retrieval from CrossRef database
  • Batch processing of multiple PDFs
  • Export to BibTeX format
  • Support for embedded PDF metadata
  • Optional GROBID integration for enhanced extraction

Prerequisites

Before using PDF Citation Extractor, ensure your system meets the following requirements:

System Requirements

  • Operating System: Windows 10 or later (64-bit)
  • RAM: Minimum 2 GB (4 GB recommended for processing large PDF collections)
  • Disk Space: At least 100 MB free space
  • Internet Connection: Required for CrossRef API lookups

Optional Requirements

  • GROBID Service (optional): For advanced PDF metadata extraction
    • Docker Desktop (if running GROBID locally)
    • Requires additional configuration (see Configuration section)

Installation

PDF Citation Extractor is distributed as a standalone executable file that requires no Python installation or dependencies.

1 Download the Application and Choose Installation Location

  1. Download the application (Download PDF Citation Scimmer Executable)

  2. Create a folder where you want to keep the application (e.g., C:\Program Files\PDF Citation Extractor\ or C:\Tools\)
  3. Copy pdf-citation-extract.exe to this folder

2 Verify Installation

Open Command Prompt and navigate to the folder containing the executable:

cd C:\path\to\your\folder
pdf-citation-extract.exe --help

You should see the help message with available options.

Quick Start

Here's the fastest way to extract citations from your PDFs:

  1. Organize your PDFs: Place all PDF files you want to process in a single folder (e.g., C:\MyPapers\)
  2. Open Command Prompt: Press Win + R, type cmd, and press Enter, then navigate to the folder containing the executable
  3. Run the extractor: 
    pdf-citation-extract.exe --dir "C:\MyPapers" --output citations.bib
  4. Find your bibliography: The citations.bib file will be created in the current directory, ready to import into your reference manager!

Usage

Command-Line Interface

The application uses command-line options to specify inputs and outputs.

Basic Syntax

pdf-citation-extract.exe [OPTIONS]

Available Options

Option Short Description Example
--dir -d Directory containing PDF files --dir C:\Papers
--pdf -p Single PDF file to process --pdf paper.pdf
--output -o Output file path (default: citations.bib) --output refs.bib
--format -f Output format (default: bibtex) --format bibtex
--config -c Path to custom config file --config config.yaml
--verbose -v Enable detailed logging --verbose
--help Show help message --help
Note: You must specify either --dir (for batch processing) OR --pdf (for single file), but not both.

Processing a Directory

To process all PDF files in a folder:

pdf-citation-extract.exe --dir "C:\Users\YourName\Documents\Papers" --output my_references.bib

Processing a Single PDF

To process just one PDF file:

pdf-citation-extract.exe --pdf "C:\Users\YourName\Documents\important_paper.pdf" --output citation.bib

Custom Output Location

Save the output file to a specific location:

pdf-citation-extract.exe --dir "C:\Papers" --output "C:\MyDocuments\bibliography.bib"

Verbose Mode

Get detailed information about the extraction process:

pdf-citation-extract.exe --dir "C:\Papers" --output citations.bib --verbose

Configuration

Default Configuration

The application works out-of-the-box with default settings. However, you can customize behavior using a configuration file.

Creating a Custom Configuration

  1. Create a file named config.yaml in the same folder as the executable
  2. Copy and modify the following template:
# PDF Citation Extractor Configuration

# Email for CrossRef API (polite pool - faster response)
# Providing your email gets you faster API responses
crossref_email: "your.email@example.com"

# Output settings
default_output_format: "bibtex"
output_directory: "./output"

# Extraction settings
extraction:
  # Number of pages to scan for DOI (1-5 recommended)
  doi_scan_pages: 3

  # Extraction strategy order
  strategy:
    - "embedded_metadata"  # Try PDF metadata first
    - "doi_lookup"         # Then try DOI extraction + CrossRef
    # - "grobid"           # Uncomment if GROBID service is available

# GROBID service configuration (optional)
# Requires GROBID Docker container running
grobid_url: "http://localhost:8070"

Using Custom Configuration

pdf-citation-extract.exe --dir "C:\Papers" --config "C:\MyConfig\config.yaml"

CrossRef Email Configuration

Providing your email to CrossRef's API moves you to their "polite pool," which provides:

  • Faster response times
  • Higher request limits
  • Better reliability

Simply add your email to the config.yaml file or leave it empty for standard access.

Troubleshooting

Issue: "No citations extracted"

Possible Causes:

  • PDFs don't contain DOI information
  • PDFs are scanned images (not text-searchable)
  • Network connection issues preventing CrossRef lookups

Solutions:

  1. Check if PDFs are text-searchable (try selecting text in the PDF)
  2. Verify internet connection
  3. Run with --verbose flag to see detailed error messages
  4. Check pdf_citation_extractor.log for more information

Issue: "Cannot find pdf-citation-extract.exe"

Solution: Make sure you're in the correct directory:

cd C:\path\to\folder\containing\exe

Or use the full path:

"C:\path\to\pdf-citation-extract.exe" --dir "C:\Papers"

Issue: Some PDFs fail to process

This is normal! Not all PDFs contain extractable metadata. Reasons include:

  • PDF is a scanned image without OCR
  • No DOI present in the document
  • DOI is malformed or not recognized
  • Embedded metadata is missing or corrupted

Solutions:

  • For scanned PDFs, use OCR software first
  • Manually add citations for failed PDFs
  • Consider using GROBID integration for better extraction

Issue: CrossRef lookups are slow

Solutions:

  1. Add your email to config.yaml to use the polite pool: 
    crossref_email: "your.email@example.com"
  2. Check your internet connection speed
  3. Process smaller batches of PDFs at a time

Issue: Permission denied when writing output file

Solutions:

  1. Ensure you have write permissions in the output directory
  2. Close any programs that might have the output file open
  3. Try saving to a different location: 
    pdf-citation-extract.exe --dir "C:\Papers" --output "%USERPROFILE%\Desktop\citations.bib"

Issue: "Error: Must specify either --dir or --pdf"

Solution: You forgot to specify input files. Use either:

pdf-citation-extract.exe --dir "C:\Papers"        # For directory
pdf-citation-extract.exe --pdf "paper.pdf"        # For single file

FAQ

Q: What PDF formats are supported?

A: Standard PDF 1.4 and higher. The PDFs should be text-based (not scanned images unless OCR has been applied).

Q: Can I process password-protected PDFs?

A: No, password-protected PDFs cannot be processed. You'll need to remove the password first.

Q: What if my PDF doesn't have a DOI?

A: The tool will try to extract embedded metadata. If that's insufficient, the PDF will be skipped. Consider adding the citation manually or using GROBID integration.

Q: Can I import the .bib file into EndNote?

A: Yes! While the tool generates BibTeX format, EndNote can import .bib files. Go to File → Import in EndNote and select BibTeX as the import filter.

Q: How do I import citations into Zotero?

A: In Zotero: File → Import → Select your .bib file → Click "Open"

Q: How do I import citations into JabRef?

A: In JabRef: File → Import into current library → Select "BibTeX" → Choose your .bib file

Q: Can I process PDFs from cloud storage (Google Drive, Dropbox)?

A: Yes, but you need to download them to your local computer first. The tool doesn't access cloud storage directly.

Q: Does this work offline?

A: Partially. Embedded metadata extraction works offline, but CrossRef API lookups require internet connection.

Q: How many PDFs can I process at once?

A: There's no hard limit, but processing large collections (100+ PDFs) may take time. Consider processing in smaller batches for better control.

Q: Is my data sent anywhere?

A: Only DOI numbers are sent to CrossRef's public API to retrieve metadata. No PDF content is uploaded anywhere.

Q: Can I contribute or report issues?

A: This is an open-source project! Check the repository for contribution guidelines and issue reporting.

Q: What if I get duplicate entries?

A: This can happen if you process the same PDF twice. Most reference managers can detect and merge duplicates.
